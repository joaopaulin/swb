# Simple Wireframe Builder

Uma aplicação web simples para criar **wireframes de telas e formulários** diretamente no navegador.

A ferramenta permite montar protótipos rápidos arrastando componentes para um canvas com **grid e snap automático**, simulando elementos com aparência semelhante ao Bootstrap.
Os wireframes também podem ser **exportados como imagem PNG**.

A aplicação funciona **100% client-side**, utilizando apenas um único arquivo `index.html`.
